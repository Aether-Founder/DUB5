# Assets

This directory contains optional reusable visual assets and icon references.

## Purpose

Optional reference assets that can be used when implementing the DUB5 design system.

## Contents

- **icons/** — Icon SVG files following the DUB5 icon style
- **logos/** — Brand mark variations
- **patterns/** — Reusable visual patterns

## Icon Style

DUB5 uses stroke-based SVG icons with:
- Stroke width: 1.7
- Rounded line caps
- 20px × 20px standard size
- Feather Icons style

## Note

Assets are optional. The design system is fully functional without them.
